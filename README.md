## 拟核心功能

- **个人知识库**：支持笔记的创建、分类与标签化管理，构建结构化知识网络。
- **错题本管理**：记录并沉淀个人错题，支持错题解析与智能复习。
- **AI 智能交互**：接入 AI 辅助功能，提供智能问答、知识点总结与学习建议。
- **学习看板**：(暂无) 直观展示个人学习进度与知识掌握情况。

## 快速开始

### 环境要求

- Node.js 20.9
- pnpm

### 安装与运行

1. 克隆代码仓库：

   ```bash
   git clone https://github.com/lyl-10/Sbook.git
   cd Sbook

2. 安装依赖(如果没有)：

   ```bash
   pnpm install

3. 运行开发服务器：

   ```bash
   pnpm dev
   # 或者使用 npm run dev / yarn dev / bun dev

4. 在浏览器中打开 [`http://localhost:3000`](http://localhost:3000) 查看结果。

## 编辑页面

你可以通过修改 `app/page.tsx` 来开始编辑页面。当你编辑该文件时，页面会自动更新。
